# CDataframe

Description
-----------
Ce logiciel est conçu pour créer et manipuler des dataframes en langage C. 
Nous avons fait les choix suivants :
                                    Partie 1 : Dur 
                                    Partie 2 : Dur
                                    Partie 3 : Facile
Pour la partie 3 nous avons fait la section 8. "Fichier" et même si elle n'est pas incluse dans la partie 3 "Facile" 
nous avons juger bon de le mettre quand même.
Notre projet fonctionne correctement pour toute les fonctions avec les cas passants cependant il est suceptible de 
disfonctionner si jamais les valeurs entrées ne correspondent pas aux valeurs attendues.

Liste des Programmes
---------------------
1. create_cdataframe:
2. Crée un nouveau dataframe.
3. delete_cdataframe:
4. Supprime un dataframe existant.
5. delete_column_in_cdataframe:
6. Supprime une colonne spécifique du dataframe.
7. get_cdataframe_cols_size:
8. Retourne le nombre de colonnes dans le dataframe.
9. fill_cdataframe_user:
10. Remplit le dataframe en demandant à l'utilisateur d'entrer les valeurs pour chaque colonne.
11. print_cdataframe:
12. Affiche toutes les colonnes et leurs valeurs dans le dataframe.
13. printcol_cdataframe:
14. Affiche une plage spécifique de colonnes dans le dataframe.
15. printlig_cdataframe:
16. Affiche une plage spécifique de lignes dans le dataframe.
17. add_lig:
18. Ajoute une ligne au dataframe.
19. del_lig:
20. Supprime une ligne spécifique du dataframe.
21. add_col:
22. Ajoute une colonne au dataframe.
23. del_col:
24. Supprime une colonne spécifique du dataframe.
25. rename_col:
26. Renomme une colonne spécifique du dataframe.
27. is_in_cdatafram:
28. Vérifie si une valeur est présente dans le dataframe.
29. print_column_name:
30. Affiche les noms des colonnes du dataframe.
31. nb_col:
32. Compte le nombre de colonnes dans le dataframe.
33. nb_lig:
34. Compte le nombre maximal de lignes dans le dataframe.
35. nb_equal_to:
36. Compte le nombre de cellules égales à une valeur donnée dans le dataframe.
37. nb_superior_to:
38. Compte le nombre de cellules supérieures à une valeur donnée dans le dataframe.
39. nb_inferior_to:
40. Compte le nombre de cellules inférieures à une valeur donnée dans le dataframe.
41. replace_value_cdataframe:
42. Remplace la valeur d'une cellule dans le dataframe.
43. load_from_csv:
44. Charge les données d'un fichier CSV dans le dataframe.
45. export_cdataframe :
46. Exporte les données du dataframe dans un fichier CSV.

Utilisation 
---------------------
Pour utiliser ces differentes fonction vous devez les appeler directement dans le main
